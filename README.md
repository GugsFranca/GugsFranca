### 💡 O que eu faço

*   **Backend:** Desenvolvo **APIs RESTful** e **microsserviços** com **Java** e **Spring Boot**, focando em código limpo e escalável.
*   **Frontend:** Crio interfaces de usuário dinâmicas e responsivas com **React**, **Next.js** e **TypeScript**.
*   **Banco de Dados:** Modelo e gerencio bancos de dados relacionais (**MySQL** ) e NoSQL (**MongoDB**).
*   **DevOps:** Utilizo **Docker** para criar ambientes consistentes e automatizo pipelines de CI/CD com **GitHub Actions**.
